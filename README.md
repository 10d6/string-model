# String Model

A physically modelled bowed string instrument (violin first; cello, viola and
bass to follow), built on [synthkit](https://github.com/10d6/synthkit). It
runs in the browser and as a VST3 / AU plugin.

A waveguide string, bowed through Woodhouse's thermal friction model, is
driven by a gesture layer that turns keys into bow speed, force and
position. The physics follows
[10d6/instrument-research](https://github.com/10d6/instrument-research).
How it works: [docs/MODEL.md](docs/MODEL.md). Roadmap: [docs/PLAN.md](docs/PLAN.md).

## Playing it from a keyboard

| | |
|---|---|
| Velocity | how hard the note starts, and its dynamic |
| Mod wheel / CC 11 | dynamics (bow speed and distance from the bridge together) |
| Aftertouch | bow pressure: airy ↔ crunchy |
| CC 74 | contact point: sul tasto ↔ sul ponticello |
| Pitch bend | the finger slides |
| Overlapping keys | slur (same bow); separate keys change bow |

## Playing it

- **In the browser:** every PR gets a preview link (posted on the PR), and
  `main` is at the repo's GitHub Pages site. This needs GitHub Pages turned
  on once: Settings → Pages → Deploy from a branch → `gh-pages` / root.
- **In your DAW:** each PR's CI run has a **plugin-windows**, **plugin-macos**
  and **plugin-linux** download (under *Checks → CI → Summary → Artifacts*).
  Unzip it and follow `INSTALL.md` inside. Tagging a version (`v0.2.0`)
  publishes them as a release.

## Building

```
git clone --recursive <this repo>
cmake -S . -B build && cmake --build build
./build/stringmodel_render --check . --out renders     # every check; WAVs into renders/
```

The browser page and the plugins are built the same way as in synthkit: see
[`synthkit/API.md`](synthkit/API.md) §11–12.

## Layout

| | |
|---|---|
| `synth.json` | identity (name, IDs, plugin codes) and kit features |
| `model/` | the physical model (plain C++, no synthkit): string, friction, gesture layer, instrument data |
| `src/` | the synth: parameters, events, output stage; `src/ir/` is generated by `tools/gen_ir.py` |
| `data/` | CC0 library-mic impulse responses (derived from VSCO-2-CE, via instrument-research) |
| `tools/` | offline labs (`string_lab`, `instrument_lab`) and `analyze.py` |
| `docs/` | `MODEL.md` (how it works), `PLAN.md` (roadmap) |
| `presets/` | factory presets (`init.json` is what a new instance starts on) |
| `tests/` | render scenarios checked in CI |
| `ui/layout.json` | the panel layout (and `ui/custom.js` for custom widgets, `ui/style.css` for styles, or `ui/page.js` for a page of the synth's own: API.md §9a) |
| `synthkit/` | the kit, as a pinned submodule |
